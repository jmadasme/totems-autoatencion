# rec/ — video explicativo

Este directorio contiene el video asciinema de **Tótem de autoatención en Win32 puro** y el reproductor
que se usa en la página del proyecto.

- `totems-autoatencion.cast`: grabación original (asciicast v2).
- `totems-autoatencion.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:14. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
